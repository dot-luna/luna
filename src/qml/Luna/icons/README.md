# Icons

Selected SVGs from [Lucide](https://github.com/lucide-icons/lucide), revision `70562c1ee1c4fdcf736fe97bc893fb8511927934`.

The included LICENSE contains Lucide’s ISC notice and the MIT notice for Feather-derived icons. No icon font or runtime download is required.

SVG strokes are normalized to white so Qt can tint them with the active theme.
