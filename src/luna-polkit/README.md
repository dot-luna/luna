# Luna authentication agent

Themed administrator prompts using Quickshell's native polkit backend. Runs
separately from the bar and launcher so reloading them does not interrupt prompts.

Run `luna auth start` to activate it and `luna auth status` to check readiness.
Hyprland starts the agent at login.

See [DOCS.md](DOCS.md) for commands, KDE replacement, keyboard controls, and checks.
