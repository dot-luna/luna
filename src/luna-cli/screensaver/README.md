# Screensaver commands

`luna screensaver` shows the selected shell. `start` runs the idle controller;
`stop`, `restart`, `reload`, `hide`, `status`, and `state` manage it.

Use `install PATH`, `list`, `set NAME`, `remove NAME`, and `dir` for the shell library.
`get-config`, `update-config`, and `get-config-file` share the public Lua API.
Use `luna idle` for timeouts and `luna awake` for temporary Stay awake controls.

See [screensaver documentation](../../screensaver/DOCS.md) for configuration,
custom shells, and the Lua/QML APIs.
