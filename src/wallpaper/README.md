# Luna Wallpaper

A Quickshell wallpaper app for images, animated images, and videos. Supports one monitor, fit modes, image fades, and a dark fallback on errors.

Setup creates your config with the selected theme's wallpaper and background color. Later installs preserve your edits.

See [config.toml](config.toml) for all configuration options and the config file location.

See [DOCS.md](DOCS.md) for the Lua and Quickshell APIs.
